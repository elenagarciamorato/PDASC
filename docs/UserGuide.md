# Python Utilities Guide

This document describes the command-line utilities provided by the PDASC repository.

The repository includes two complementary sets of utilities:

- **Experimentation utilities**, used to execute and benchmark ANN algorithms under a unified evaluation pipeline.
- **Distance distribution analysis utilities**, used to study the statistical properties of datasets and PDASC indices. These tools supported the development and evaluation of the ECDF-based exploration strategy proposed for PDASC.

---

# Experimentation Utilities

## Typical Workflow

The standard experimentation workflow is:

```text
1. Create an experiment CSV file.
          ↓
2. Execute the experiments.
          ↓
3. Benchmark the generated results.
```

---

# Experiments Launcher

## Overview

The `experiments_launcher.py` utility executes batches of ANN experiments described in CSV files.

Each row of the CSV corresponds to an independent experiment. The launcher automatically configures the selected ANN method, executes the search and stores both the search results and the associated performance statistics.

All supported ANN methods share the same launcher and execution pipeline, ensuring reproducible and fair comparisons under identical experimental conditions.

---

## CSV Experiment Files

Experiments are described using CSV files.

Each row represents a single experiment.

The first columns correspond to the parameters shared by all supported ANN methods.

| Parameter | Description |
|-----------|-------------|
| `k` | Number of nearest neighbours to retrieve. |
| `dataset` | Dataset name. |
| `method` | ANN algorithm. |
| `distance` | Distance (or similarity) function. |

The remaining columns correspond to the parameters required by the selected ANN algorithm. Columns that are not applicable to a particular method can simply be left empty.

### Method-specific Parameters

| Method | Parameters |
|---------|------------|
| PDASC | `nc`, `tg`, `r`, `n_nodes`, `algorithm`, `implementation` |
| PyNNDescent | `nn`, `diversification`, `pruning`, `epsilon` |
| Annoy | `n_trees`, `k_search` |
| FAISS IVF | `nlist`, `nprobe` |
| FAISS HNSW | `M`, `efConstruction`, `efSearch` |
| NMSLIB HNSW | `M`, `efConstruction`, `efSearch`, `post` |
| FAISS LSH | `nbits` |
| Exact Search | *(no additional parameters)* |

### Example

```csv
k,dataset,method,distance,nc,tg,r,n_nodes
10,GLOVE,PDASC,cosine,500,1000,0.9919,5
10,GLOVE,PDASC,cosine,500,5000,0.9919,5
10,GLOVE,PDASC,cosine,500,1000,1.0204,5
```

---

## Usage

```bash
python3 -m ANN_Experiments.experiments_launcher <experiment_file.csv>
```

### Example

```bash
python3 -m ANN_Experiments.experiments_launcher test_knn_GLOVE_PDASC_cosine.csv
```

---

## Output

For each experiment, the launcher stores:

- Retrieved nearest neighbours.
- Corresponding distances.
- Number of Distance Computations (NDC).
- Index size.
- Index construction time.
- Additional metadata required for reproducibility.

The generated HDF5 files can be directly processed by the benchmarking utilities.

---

# Performance Benchmarking

## Overview

The benchmarking utilities aggregate the statistics generated by the Experiments Launcher and compare the performance of different ANN methods under identical experimental conditions.

The following metrics are computed automatically:

- Recall@k
- Number of Distance Computations (NDC)
- Index Size
- Index Construction Time
- Query Processing Time

---

## Usage

```bash
python3 -m ANN_Experiments.benchmark.performance_benchmark <dataset_name> [optional_filters]
```

### Examples

Benchmark all experiments for a dataset:

```bash
python3 -m ANN_Experiments.benchmark.performance_benchmark NYtimes
```

Benchmark only cosine PDASC experiments:

```bash
python3 -m ANN_Experiments.benchmark.performance_benchmark NYtimes cosine PDASC
```

# Distance Distribution Analysis

The repository also provides a set of independent utilities for analysing the statistical distribution of distances in datasets and PDASC indices.

These tools were developed to study the structural properties preserved by the PDASC hierarchy and to support the design and evaluation of the ECDF-based exploration strategy proposed for PDASC. They are independent from the standard experimentation and benchmarking workflow.

---

# Distance Distribution Generation

## Overview

The `distances_distribution_generator.py` utility generates Probability Density Functions (PDFs) and Cumulative Distribution Functions (CDFs) from both random samples of a dataset and the prototypes composing different layers of a PDASC index.

The resulting distributions can be used to analyse how accurately the PDASC hierarchy preserves the statistical properties of the original dataset.

---

## Usage

```bash
python3 -m dataset_analysis.distances_distribution_generator \
    -<distribution> \
    "('dataset','distance')" \
    -np <nc> \
    -gl <tg> \
    -size <sample_size> \
    -nodes <n_nodes>
```

---

## Supported Analyses

| Option | Description |
|---------|-------------|
| `-pdfsNN` | kNN distance PDFs |
| `-pdfsPW` | Pairwise distance PDFs |
| `-cdfsNN` | kNN distance CDFs |
| `-cdfsPW` | Pairwise distance CDFs |
| `-cdfsNN_SS` | kNN distance CDFs for different sample sizes |
| `-cdfsPW_SS` | Pairwise distance CDFs for different sample sizes |

---

## Parameters

| Parameter | Description |
|-----------|-------------|
| `-np` | Number of centroids (`nc`) used during clustering. |
| `-gl` | Group size (`tg`). |
| `-size` | Sample size expressed as a percentage of the dataset. |
| `-nodes` | Number of distributed nodes composing the PDASC index. |

**Note:** Dataset and distance arguments must be provided as Python tuples, for example:

```text
("municipios", "haversine")
```

---

## Example

```bash
python3 -m dataset_analysis.distances_distribution_generator \
    -cdfsPW \
    "('municipios','haversine')" \
    -np 30 \
    -gl 60 \
    -size 10 \
    -nodes 3
```

---

# Distance Distribution Evaluation

## Overview

The `distances_distribution_evaluation.py` utility statistically compares the distributions generated from random dataset samples and PDASC prototypes.

The comparison relies on two complementary statistical measures:

- Kolmogorov–Smirnov statistic
- Wasserstein distance

---

## Usage

```bash
python3 -m dataset_analysis.distances_distribution_evaluation \
    -dataset <dataset> \
    -dist <distance> \
    -size <sample_size> \
    -nodes <n_nodes>
```

---

## Example

```bash
python3 -m dataset_analysis.distances_distribution_evaluation \
    -dataset MNIST \
    -dist euclidean \
    -size 10 \
    -nodes 3
```

---

## Output

The utility reports:

- Kolmogorov–Smirnov statistic.
- Associated p-value.
- Wasserstein distance.
- Interpretation of the statistical significance.
